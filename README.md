# Avenx-JS Support

This extension provides syntax highlighting, snippets and basic support for Avenx-JS development.

## Features

- **Syntax Highlighting**: Support for `.axt`, `.axd`, and `.avx` files.
- **Snippets**: Productivity snippets for Avenx Templates and Definitions.
- **Avenx Sidebar**: Quick access to Avenx tooling info.

## File Types

- `.axt`: Avenx Template (HTML with Logic)
- `.axd`: Avenx Definition (CSS with Scopes)
- `.avx`: Avenx Script (JavaScript)
